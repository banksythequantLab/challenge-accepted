Make the tools openable, because that is the demo

The pitch is "the agents built you a tool" and the app had no way to open one.
The quest card offered "Copy tool" -- a clipboard button for a thing nobody had
seen. On camera that beat is dead: you cannot show a judge a checklist by
copying it.

Added a tool viewer. Click a step's tool and it opens a modal that renders the
artifact by what it actually is, rather than dumping a blob of text:

  mini_app        real iframe, sandbox="allow-scripts allow-forms allow-modals"
                  and no allow-same-origin, so agent-written HTML runs live but
                  cannot reach into the page
  checklist       parsed JSON rendered as tickable items
  calculator      syntax-styled source
  research_brief  prose
  script          prose

Shape detection is defensive on purpose -- the agents write this JSON, so
checklistItems() accepts items|steps|checklist|tasks|list and reads the label
from text|item|task|label|title|step|name|description before giving up and
falling back to source view. A malformed tool degrades to something readable
instead of an empty box.

"Open tool" is now the primary action on the quest card. Copy tool, Download and
Copy for Claude moved into the modal footer, where they follow looking at the
thing rather than replacing it.

The seeded demo tools were placeholders, which would have looked exactly as thin
as they were. scripts/demo_tools.py gives all five real bodies: a working pacing
calculator, a six-item backend checklist, a hosting comparison, a demo script
template, and STATE_SIMULATOR -- an actual HTML mini-app with animated worker
bars that drains a queue when you click Start.

scripts/check_tools.py opens every tool and asserts the right renderer fired.
The mini_app case clicks Start and polls for completion; my first version used a
fixed 2500ms wait and reported a failure that was really my timeout being
shorter than the slowest simulated worker. Fixed the test, not the app.

52 tests pass. check_tools and check_copy pass. Console clean.
